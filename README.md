# 三国富甲天下（Web 版）

仿照光谱资讯经典游戏《富甲天下2》，把「大富翁」式掷骰走格与「三国」题材的模拟经营结合起来的网页小游戏。

纯前端实现：**不需要构建、不需要后端、不需要联网**（唯一的三方库 three.js 已随仓库内置，见 `js/lib/`）。

> 仓库地址：<https://github.com/kallr/sanguo16>

---

## 立即开始

**方式一（最简单）**：直接双击 `index.html`，浏览器打开即玩。

**方式二（本地起服务）**：仓库是纯静态项目，把目录用任意静态服务器跑起来即可，例如

```bash
python -m http.server 8123      # 然后访问 http://localhost:8123
```

**方式三（线上部署）**：本项目无需编译，可直接用 GitHub Pages 托管 —— 见下方 [部署到 GitHub Pages](#部署到-github-pages)。

## 部署到 GitHub Pages

本项目是纯静态页面，仓库根目录就是站点根目录，开启 Pages 后即可在线游玩。

1. 打开仓库 **Settings → Pages**：<https://github.com/kallr/sanguo16/settings/pages>
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. **Branch** 选 `main`、目录选 **/ (root)**，点 **Save**。
4. 等 1~2 分钟，页面顶部会显示访问地址：<https://kallr.github.io/sanguo16/>

之后每次 `git push` 到 `main`，站点会自动更新。由于全部脚本与样式都走相对路径、也没有构建产物，**不需要额外配置任何部署工作流**。

## 玩法

### 目标

- **统一天下**：占领棋盘上全部城池与关隘，或把其他势力全部淘汰，立即获胜。
- **富甲天下**：打到回合上限仍未分胜负时，按总资产排名定输赢。
  总资产 = 金 + 城池估值 + 兵力 × 3 + 粮 ÷ 2。

### 一个回合做什么

```
结算城池收益 → 掷骰 → 逐格移动 → 落地结算 → 自由经营（可多次）→ 结束回合
```

- **结算**：己方城池按时产出金 / 粮 / 兵，同时按兵力消耗粮草（每 10 兵耗 1 粮）。粮草不够会引发士卒逃亡。
- **移动**：每格有独立动画，途经起点领取 300 金俸禄。
- **落地**：按脚下格子的类型触发对应事件（见下）。
- **经营**：升级城池、建造设施、招募武将、出兵攻城、调兵遣将，想做完几件都行，最后手动结束回合。

### 棋盘格子

| 类型 | 数量 | 说明 |
|---|---|---|
| 起点 | 1 | 途经或落脚领 300 金 |
| 城池 | 24 | 可占领、可升级、可建设，是主要收入来源 |
| 关隘 | 2 | 可占领收过路费，但不能升级与建设 |
| 农田 | 4 | 落脚领 200 粮 |
| 招贤馆 | 2 | 落脚可招募在野名将 |
| 事件 | 5 | 抽事件卡，好坏参半 |
| 机会 | 2 | 抽机会卡，多为利好 |

棋盘按四个地域分片：**中原、河北、江东、巴蜀**。

### 遇到别人的城池：交税，还是宣战？

落在敌方城池上会弹出二选一：

- **交税**：老实付过路费。过路费 = 该城基础收益 × 等级 × 1.2。
- **宣战**：就地打一场**野战**。胜了免付过路费，还能反过来掠夺对方钱财；败了要赔**双倍**过路费。

另外，抽到「免过路金牌」可在若干回合内免费通行。

### 三种战斗

| 模式 | 触发方式 | 特点 |
|---|---|---|
| 单挑 | 每场交战的前置环节 | 双方主将按武力对决，胜者全军士气大振（战力 +18%） |
| 野战 | 路过敌城选择「宣战」 | 无守城加成，纯拼兵力与统率 |
| 攻城战 | 行动阶段「出兵攻城」 | 守方吃等级、练兵场、护城河的防御加成；胜则夺城并留兵驻守 |

战力大致为 `兵力 × (1 + 统率/200 + 武力/500) × 士气 × 随机浮动`，守方再乘守城加成。
**出兵只能打与己方城池相邻的敌城**，所以是步步为营向外扩张。

### 招贤馆与「相性」

招募名将不只看钱，还要看**合不合得来**——这正是原作那个「招募要看是否合得来」的机制：

- 每位武将都有心仪的势力倾向。诸葛亮对刘备相性 80，对曹操只有 20。
- 相性越高，招募成功率越高；话不投机者，散尽钱财也难请动。
- 刘备的势力特性「仁德」会让招募费打八折，并额外提升相性判定。

开局每位君主各带 2 员大将，另有 30 余名在野名将散布天下（关羽、张飞、赵云、周瑜、司马懿、吕布、貂蝉……共 44 员）。

### 城市建设

城池最高 5 级，每城最多 4 个建筑槽（每种限一个）：

| 建筑 | 效果 |
|---|---|
| 市集 | 金收益 +30% |
| 农田 | 粮收益 +60（曹操「屯田」再 +30%） |
| 练兵场 | 兵员补充 +30，守城防御 +25% |
| 护城河 | 守城防御 +35% |

升级与建设成本都随等级 / 建筑数量递增，避免无脑堆钱。

### 势力特性

| 势力 | 特性 | 效果 |
|---|---|---|
| 刘备 | 仁德 | 招募费用 −20%，相性判定 +10 |
| 曹操 | 屯田 | 农田产粮 +30% |
| 孙权 | 江东 | 江东地域城池收益 +20% |
| 董卓 | 暴虐 | 战斗掠夺 +50%，初始兵力 +300，但过路费收入 −15% |

### 联片加成

同一地域占有 3 座以上城池，该地域所有城池收益 **+15%**，鼓励按地域成片扩张。

### 事件与机会卡

共 38 张（22 张事件 + 16 张机会），涵盖钱粮增减、天灾兵损、强制前进、免过路金牌、掠夺敌方、名将主动来投等。

### 破产

现金为负时会自动变卖城池抵债（七折）。无地可卖仍为负，势力即告覆灭。

## 界面与操作

- **2D / 3D 视角**：棋盘默认真 WebGL 三维渲染（three.js），按《富甲天下2》的地图模式做成一张**草地沙盘**——40 个石板格沿一条**闭合的巡游路网**铺开，地域按史地方位摆放：**中原**在中部拱行（洛阳、许昌、陈留…），**江东**沿东侧自东南向东北（会稽、建业、合肥…），**河北**横贯北侧（蓟城、邺城、晋阳…），**巴蜀**沿西侧自北向南再折返中部闭合成环（汉中、成都、江州…）；城池在路旁立着**木构小屋 / 栏杆高台 / 小红旗**（规模从乡村一路长到王城），路旁点缀圆冠树与旗杆，一条河流自西向东蜿蜒横穿中原、路面压过河床形成 4 处过河桥，零星几处小水塘与土坡。默认固定等角 45° 俯视（也可拖拽旋转、滚轮缩放），取景随偏航/俯仰即时重算，地图始终填满画面且不会被裁切。骰子与操作按钮在右侧栏顶部。顶栏第一个按钮 `3D`／`2D` 可切回平面棋盘（同一套坐标、同一张底纹），选择会被记住；小屏设备默认 2D，WebGL 不可用时自动降级 2D 并提示。
- 顶部侧栏是当前势力的骰子与操作按钮区；右侧下方是势力面板与滚动战报。
- **鼠标悬停**任意格子可查看归属、收益、过路费、驻军、防御力等详情。
- 顶栏按钮：`3D/2D` 切换视角 · `?` 玩法说明 · `存` 手动存档 · `导` 导出存档文本 · `入` 导入存档 · `≡` 返回主菜单。
- 当棋盘中央只有一个按钮时，按 **空格键** 可代替点击（掷骰子 / 结束回合时很方便）。

## 技术说明

- **为什么用普通 `<script>` 而不是 ES Module**：`file://` 协议下 ES Module 与 `fetch` 会被 CORS 拦截，为了让「双击 `index.html` 就能玩」成立，所有脚本按固定顺序以经典脚本加载并挂到全局命名空间 `SG`，数据表也写成 `.js` 常量而非 `.json`。
- **数据驱动**：城池、武将、卡牌、势力、剧本全部独立成表，逻辑与数据分离，加内容只需改数据文件。
- **人机统一决策**：引擎只 `await` 一个决策值——人类由弹窗 Promise 提供，电脑由 `ai.js` 提供，规则层不感知人机差异。
- **防竞态**：全局 `busy` 锁 + Promise 动作队列，动画播完才结算；另设「代际守卫」，保证新开一局不会被上一局残留的异步循环污染。
- **回合级异常兜底**：单个势力的一回合出错会被捕获并跳过（同时写入战报），不会让整局卡死。
- **美术**：除 three.js 本体外零外部素材——石板砖、路面、棋子令牌等贴图都在运行时用 `CanvasTexture` 现场绘制，城池名字用 DOM 名牌浮在建筑上方，不加载任何图片，可完全离线游玩。
- **立体地图（草地沙盘）**：`js/data.cities.js` 里的 **40 格地理坐标表 `TILE_XY`**（世界单位，索引顺序即巡游顺序，两套渲染层共用）取代了早先的规整网格：中原在中部排成一道拱形路，江东沿东侧、河北沿北侧、巴蜀沿西侧，构成一条不自交的闭合环（相邻格间距约 1.0~1.9 单位）。3D 层据此生成沙盘：`PlaneGeometry` 150x150 细分（约 4.5 万三角形）铺一片缓坡草地，再用「点到路网折线的距离」把地形沿路削平成路基（`ROAD_FLAT`/`ROAD_HALF`），路外留土坡、一道东西向土脊、一条**自西向东蜿蜒的河流**（河床下切到水面以下，路面最后压过形成 4 处过河桥）与圆冠树、旗杆。**2D 平面视图也用同一套坐标现场画一张底纹**（草地 + 石板路 + 河流，canvas → dataURL），格子同样是灰色石板砖（类型只作轻度染色），所以两种视角看到的是同一张地图。**不加载任何高度图或贴图文件，全部纯代码生成**，所以仍然离线可玩。
- **3D 视角是怎么做出来的**：引入了 three.js（r147 的 UMD 构建，随仓库内置在 `js/lib/three.min.js`，用经典 `<script>` 引入，因此 `file://` 双击打开依然能跑；现代版只发 ES Module，会被 CORS 拦下）。只有地图进 WebGL：草地沙盘、石板路、路上 40 个石板格与建筑、路旁树木、棋子令牌；骰子与操作面板、弹窗、战斗演出、侧栏、悬浮提示仍是 DOM 覆层。渲染层与逻辑层彻底解耦——`board.js` 导出 `SG.Board2D`、`render3d.js` 导出 `SG.Board3D`，两者接口完全一致，`main.js` 只按当前视角把 `SG.Board` 路由到其中之一，`engine/state/ai` 一行都不用改。可调参数都集中在 `render3d.js` 顶部（`TILE_W` 石板边长、`ROAD_*` 路基/路面、`MOUNDS`/`PONDS` 土坡与水塘、`RIVER` 河床、`RIDGE` 土脊、`WATER_Y` 水面线、`VIEW_PAD` 取景留白、`Z_SCALE` 台基高度）；`fitDistance()` 按当前偏航/俯仰与画布比例算出取景距离，使整张地图刚好铺满画面。地图尺寸与路网坐标在 `js/data.cities.js`（`MAP_W`/`MAP_D`/`TILE_XY`）。

## 存档

- 每个回合结束时会自动存档到浏览器 `localStorage`。
- 部分浏览器在 `file://` 下会限制本地存储，此时会自动降级为内存存档，可用顶栏「导」把存档文本导出保存、在别的设备用「入」导入续玩。
- 主菜单的「读取存档」按钮会读取最近一次存档；读档后直接回到你的回合，无需先等电脑行动。

## 已知限制与说明

- 没有音效与背景音乐。
- 武将头像使用「姓氏首字 + 水墨底纹」的离线方案，未接入外部图片服务（本环境测试的图片接口对不同提示词返回同一张固定占位图，故不采用）。
- 电脑 AI 采用简单可解释的打分规则（保命 → 买地 → 升级 → 招募 → 出兵），参数集中在 `js/ai.js` 的 `SG.AI_PARAMS`，便于调平衡。
